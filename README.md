## 简介

MultiWorks Connected 面向需要在电脑、手机和平板之间传递工作内容的个人用户。它采用聊天式界面，通过多个可命名项目群分别管理文字、链接、PDF 和小型压缩包。

应用与数据运行在你自己的电脑上。需要公网访问时，可以使用云服务器中转，无需为家里的电脑准备公网 IP。

## 功能

| 功能 | 说明 |
| --- | --- |
| 项目整理 | 命名、分组、折叠、拖拽排序，显示创建和最近消息时间；管理入口收在 ⋯ 菜单 |
| 实时同步 | WebSocket 推送、自动重连、恢复后补齐当前群消息 |
| 文字消息 | 即时显示、失败手动重试、请求去重、可点击链接 |
| 剪贴板与图片 | Ctrl + V 粘贴截图，缩略图确认，聊天内显示图片，7 天以前按需展开 |
| 文件上传 | 全页面拖拽、多选、发送前确认、进度、取消和重试，最多两个并行上传 |
| 文件预览 | 本地 PDF 阅读器、图片、文本、Word 正文与 Excel 表格预览 |
| 文件下载 | 登录后下载、浏览器下载进度、HTTP Range 支持 |
| 历史记录 | 群内与全局搜索，可定位原消息，每次加载 100 条历史记录 |
| 文件查看器 | 独立页面，按项目、名称、类型、上传日期与大小筛选，显示上传者、时间和总大小 |
| 设备管理 | 自动推测系统和浏览器、手动命名、查看和撤销登录 |
| 临时账户 | 独立用户名和密码、指定项目授权、1 / 3 / 5 / 7 / 30 天有效期，停用与重新激活 |
| 界面偏好 | 浅色 / 深色 / 跟随系统、中英文、侧栏收起、可修改的彩色头像框 |
| 访问保护 | 服务端权限校验、会话鉴权、来源检查、登录失败限速 |
| 本地存储 | SQLite 保存账号与消息，本地磁盘保存附件 |
| 响应式界面 | 桌面与手机布局、群未读提示、会话期间的输入草稿 |

## 架构

```text
电脑 / 手机 / 平板浏览器
           │ HTTPS
           ▼
云服务器：Caddy + frps
           │ frp TLS 隧道
           ▼
服务电脑：frpc → Node.js 应用
                     ├── SQLite：账号、会话、消息
                     └── 本地磁盘：附件
```

本地使用不需要云服务器。公网方案中，云端转发请求，服务电脑持久保存业务数据，并需持续开机联网。

## 快速开始

需要 **Node.js 24 LTS**、npm 和现代浏览器。支持 Windows 和 Linux，专用服务电脑推荐 Ubuntu LTS。

### 1. 获取项目

```bash
git clone https://github.com/xiangzhong26/MultiWorksConnected.git
cd MultiWorksConnected
npm ci
```

### 2. 创建配置

Windows PowerShell：

```powershell
Copy-Item .env.example .env
```

Linux：

```bash
cp .env.example .env
```

### 3. 启动

```bash
npm start
```

在运行服务的电脑上打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)，设置至少 **12 个字符**的密码和设备名称。

**没有默认密码。先在本地完成首次设置，再开启公网中转。** 默认只监听本机，其他设备不能直接访问这个地址。跨设备访问见部署指南。

## 使用说明

### 登录与设备

1. 管理员在用户名留空（或填写 `admin`）时使用原来的访问密码登录。临时账户填写自己的用户名和密码。
2. 默认设备名称根据系统和浏览器生成，例如 `Windows · Chrome`。
3. 点击左下角设备名称，可改成“办公电脑”“手机”，或撤销某台设备的登录。
4. 手机上先打开左上角菜单，再进入设备管理或切换项目群。

设备按浏览器标识，不是硬件序列号。无痕模式或清除浏览器数据会产生新设备；会话有效期为 30 天。

### 项目群

- 点击“项目群”旁的 **＋** 新建群，例如“论文资料”“设计项目”。
- 点击左侧群名称切换工作内容。
- 点击左侧群旁的 **⋯**，可重命名、选择分组或删除；删除仍需再次确认。
- 拖动群左侧的 **⠿** 排序柄到另一群前方调整顺序；跨分组拖动会将群移到目标所在分组，排序在所有设备同步；也可选中排序柄后按上下方向键调整。
- 左侧“分组管理”创建或更名分组；分组默认折叠，可用于归档。移除分组会保留群和记录。
- 群下显示创建时间和最近消息时间。点击 **«** 收起侧栏，顶部 **☰** 展开。
- 管理员能访问全部群；临时账户只看到被授权的群。

### 文字与文件

- 输入文字后点击“发送”；桌面上 **Enter** 发送、**Shift + Enter** 换行。
- 点击“添加文件”或将文件拖入页面（包括输入框）；支持多选。
- 在输入框按 **Ctrl + V**（Mac：**⌘ + V**）粘贴文字、链接、剪贴板文件或截图。微信截图可直接粘贴，图片会先显示确认缩略图，确认发送后才上传；普通文字仍直接进入输入框。
- PNG / JPEG / GIF / WebP 图片在聊天中直接显示，点击图片可打开完整预览。7 天以前（满 7×24 小时）的图片默认只显示文件信息，点击 **👁** 展开或收起。此规则只影响显示，原图和聊天记录仍永久保存。
- 在确认窗口核对目标项目群、文件名和大小，可移除错选文件；点击“确认发送”后才开始上传。
- 查看上传百分比，按需取消；失败后点击“重试”。
- 在另一台设备打开相同群，消息与文件会实时出现。
- 点击文件卡片打开预览，或点击卡片下方“下载”；下载进度由浏览器显示。
- 桌面浏览器支持时，可把文件卡片拖到本地文件夹保存。此能力取决于浏览器和系统；如果无效或只生成链接，请使用“下载”。

默认上限 **100 MB / 文件**。上传重试重新传输整个文件，当前没有分片上传或上传断点续传。

不支持直接上传文件夹。拖入文件夹会提示先压缩成 ZIP 等压缩包；上传失败后同时提供“重试”和“取消”，无法读取的内容需取消后重新选择。

### 搜索与删除

- 顶部搜索框只搜索当前群的正文和文件名；清空搜索框返回正常记录。
- 点击“加载更早的消息”查看历史记录。
- 点击消息旁的“删除”，确认后移除消息及附件。**删除对所有设备生效，无法撤销。**

### 文件查看器与全局搜索

- 点击左侧 **文件查看器** 打开独立页面，按名称、项目群、扩展名、上传日期及大小筛选。
- 表格显示文件类型、大小、项目、上传者和时间，并显示匹配文件数与总大小。
- 点击“预览”“下载”或“定位消息”；定位会返回聊天并高亮原消息。
- 在查看器中删除文件，也会删除对应聊天消息和服务器本地附件。
- 左侧展开“全局搜索”，输入关键词查找所有群的正文和文件名，点击结果定位到原消息。
- 定位会打开所属项目群并高亮原消息，即使该消息早于最近 100 条记录。
- 历史定位后可加载后续消息，或点击“回到最新消息”。删除群会同时清理文件索引和相关搜索结果。

### 外观与语言

- “个人设置”提供浅色、深色和跟随系统主题，聊天、预览和文件查看器保持一致。
- 每个浏览器身份默认分配彩色头像边框；在个人设置中修改，新发送的消息使用新颜色，旧消息保留发送时的颜色。
- 临时账户有虚线头像框和“临时账户”标识，管理员创建或编辑时可设置其默认颜色。
- 点击 **English / 中文** 切换页面语言；主题、语言、侧栏状态和分组折叠状态保存在当前浏览器。

### 临时账户

管理员点击左侧 **账户管理 → 创建临时账户**，设置用户名、至少 12 字符的密码、授权项目群与有效期，然后将访问地址和凭据交给协作者。所有使用管理员密码登录的设备都能管理这些账户。

| 操作 | 效果 |
| --- | --- |
| 到期 / 停用 | 拒绝访问并使登录失效，账户和消息保留；没有任何授权项目时同样不能登录 |
| 取消项目授权 | 立即使现有登录失效；重新登录后只看到仍获授权的群 |
| 编辑 / 重新激活 | 从保存时刻重新计算 1、3、5、7 或 30 天有效期，可更改授权或密码 |
| 永久删除账户 | 删除账号、授权和登录会话，保留历史消息、附件、发送者名称及临时标识 |

临时账户可以在授权群内聊天、上传、预览、下载，以及删除当前浏览器自己发送的消息；不能创建、编辑、排序或删除项目群，不能管理账户和其他设备。密码不会以明文保存，也无法在保存后查看。

### 长期记录与加载速度

打开群直接定位最新消息，每次最多读取 100 条；页面最多保留 300 条已加载记录，继续翻页会替换浏览器中的窗口。数据库中的旧记录不受影响，可继续翻页或搜索定位。长时间断线后只补取最近窗口，避免逐条回放全部历史。

### 预览格式与限制

| 格式 | 预览方式 |
| --- | --- |
| PDF | 服务自带 PDF 阅读器，支持翻页、缩放、提取当前页文字，不执行 PDF 脚本 |
| PNG / JPEG / GIF / WebP | 图片预览 |
| TXT / Markdown / CSV / JSON 及常见代码文件 | 纯文本显示，最多显示前 1 MB；HTML 也只显示源码 |
| DOCX | 提取 Word 正文，不保留完整排版，最多显示 20 万字符 |
| XLSX | 工作表内容，最多 10 张表、每表 200 行和 30 列，不执行公式或宏 |
| 其他格式 | 提供原文件下载，包括旧版 DOC / XLS、压缩包或无法处理的文档 |

预览在本地完成，不将内容发送到第三方。Office 文件预览上限为 10 MB，转换有时间和内存限制；加密或损坏文件需下载后打开。预览为只读，不支持在线编辑。

## 配置

配置写入本地 `.env`，修改后重启应用。

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 监听地址，默认仅本机访问 |
| `PORT` | `3000` | 应用端口 |
| `DATA_DIR` | `./data` | 数据目录，相对路径基于进程工作目录 |
| `PUBLIC_ORIGIN` | 空 | 公网来源，如 `https://work.example.com`，末尾不加 `/` |
| `COOKIE_SECURE` | `false` | 正式 HTTPS 部署设为 `true` |
| `MAX_FILE_MB` | `100` | 单文件上限，单位 MB |

以项目根目录作为工作目录。生产环境建议使用绝对数据路径，例如 `/var/lib/multiworks`。

## 安全与隐私

**聊天记录和附件没有自动过期清理，也没有保存条数上限。** 每次查询 100 条只是分页，不会删除旧记录；30 天过期仅指登录会话。数据持续保存在 `DATA_DIR` 中，直到你主动删除消息或项目群，或数据目录被外部操作删除、磁盘损坏或空间不足。更新、重启或换电脑部署时保留并使用原数据目录，建议定期备份。

- 密码以 scrypt 加盐哈希保存；Cookie 使用 `HttpOnly`、`SameSite=Strict`，正式 HTTPS 部署开启 `Secure`。
- 消息、搜索、附件、预览和 WebSocket 推送均执行项目授权校验；管理员保留完整管理权限。
- 公网使用 HTTPS；frp 示例强制 TLS，建议配置证书验证以确认中转服务器身份。
- HTTPS 在云端终止，云管理员技术上可以读取转发内容。**没有端到端加密，也没有数据库或附件静态加密。**
- 不要提交真实 `.env`、frp 配置、私钥、数据库、附件、日志或备份。
- 测试密码仅用于隔离测试；示例 token 是占位符，不是默认凭据。

默认数据结构：

```text
data/
├── workspaces.sqlite      # 账号、设备、会话、群和消息
├── workspaces.sqlite-wal  # 运行时可能存在
├── workspaces.sqlite-shm  # 运行时可能存在
└── files/                 # 随机文件名保存的附件
```

`.gitignore` 排除默认数据和常见敏感配置，不能阻止强制提交，也不能自动保护所有自定义附件目录。更改数据路径后将它放在仓库外或增加忽略规则。备份时停止服务、复制整个数据目录、再启动；备份包含敏感内容和有效会话。

## 常见问题

**其他设备打不开 `127.0.0.1:3000`？**

该地址指向访问设备自身。默认配置仅供服务电脑本机使用，跨设备访问需要中转入口。

**页面打不开或一直重连？**

检查服务电脑是否开机、联网且未睡眠，再检查应用、frpc、云端 frps 和 Caddy。

**提示来源不匹配？**

确认 `PUBLIC_ORIGIN` 与访问地址一致，包括协议和端口，不带末尾斜杠。修改后重启。

**上传失败？**

检查 `MAX_FILE_MB`、磁盘空间和网络。网络恢复后可重试，整个文件会重新上传。

**支持团队与多个账号吗？**

支持临时协作者账号和项目群授权。使用管理员密码的设备权限相同；临时账号权限受限。目前没有审计日志、企业组织或账号自助注册。
